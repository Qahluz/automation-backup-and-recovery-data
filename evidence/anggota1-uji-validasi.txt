1. TUJUAN PENGUJIAN

Pengujian dilakukan untuk memastikan modul validation.sh mampu memeriksa parameter, keberadaan direktori sumber, jenis direktori sumber, dan kelayakan direktori tujuan sebelum proses backup dijalankan.

2. HASIL PENGUJIAN UTAMA PADA UBUNTU SERVER

T01 – Validasi sumber dan tujuan valid

Kondisi:
Direktori sumber tersedia dan direktori tujuan dapat digunakan.

Hasil aktual:
Validasi berhasil.
Exit status: 0
Status: LULUS

T02 – Direktori sumber tidak ditemukan

Kondisi:
Direktori sumber yang diberikan tidak tersedia.

Hasil aktual:
Error: Direktori sumber tidak ditemukan.
Exit status: 3
Status: LULUS

T02 Tambahan – Sumber bukan direktori

Kondisi:
Parameter sumber menunjuk ke berkas biasa, bukan direktori.

Hasil aktual:
Error: Sumber bukan direktori.
Exit status: 3
Status: LULUS

T03 – Parameter kurang

Kondisi:
Script dijalankan tanpa memberikan parameter sumber dan tujuan.

Hasil aktual:
Error: Parameter harus terdiri dari sumber dan tujuan.
Exit status: 2
Status: LULUS
