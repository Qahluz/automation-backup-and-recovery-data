# Bukti Pengujian dan Demonstrasi Ubuntu Server

Proyek: Sistem Otomasi Backup dan Pemulihan Data Linux

Pengujian dilakukan secara langsung pada Ubuntu Server.

| Folder | Pengujian |
|---|---|
| 00-environment | Lingkungan pengujian |
| 01-validation | Validasi sumber dan parameter |
| 02-backup | Pembuatan arsip |
| 03-checksum | Verifikasi SHA-256 |
| 04-restore | Pemulihan data |
| 05-access-control | Permission |
| 06-lock-log-report | Lock, log, laporan |
| 07-monitoring | Monitoring |
| 08-docker | Read-only bind mount |

Setiap pengujian didokumentasikan menggunakan command,
hasil aktual, exit status, dan screenshot.
